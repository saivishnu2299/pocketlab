# Changelog

## 1.1.0 — public-release preparation (unpublished)

- One-line agent setup: the README prompt points any local coding agent at the repository, and AGENTS.md opens with a step-by-step setup playbook.
- `./pocketlab cards` lists mounted SD cards, their state, and the single command that sets each one up (`--json` for agents). It explains the macOS removable-volume privacy refusal instead of failing with a bare "Operation not permitted".
- Card setup and diagnostics run on Python 3.9+, including the Python bundled with macOS; building mini apps still needs 3.12+.
- `doctor --sd` reports when a card's runtime is older than the bundled one.
- Fix: blank-card preparation no longer fails at its final cleanup on macOS FAT cards with Python 3.9–3.12, when AppleDouble companions vanish together with their files. PocketLAB also removes the macOS `._*` companions of its own runtime files.
- `--eject` retries while Spotlight finishes indexing a freshly written card. If the card stays busy, a finished setup no longer exits with an error.
- New Apps-screen icon that matches the stock TrimUI icon template (300×300, continuous-corner tile) and uses the PocketLAB library mark. Generated by `tools/icon_art.py`.
- Fix: the Apps screen drew the PocketLAB icon twice, as a second offset copy behind the tile. `config.json` set the image as both `icontop` and `icon`; it now sets only `icontop` and leaves `icon` empty, like every stock app and emulator. Runtime verification rejects a configuration that sets both.
- Preserve the existing PocketLAB UI, assets, ESP32 detector, and Starfall implementation.
- Include only those two default apps; provide neutral SDK scaffolding and independent test fixtures.
- Bundle a verified ARM64 runtime for installation without compilation.
- Build with a pinned native toolchain and upstream SDL import metadata without a private device-library cache.
- List mounted cards by name and capacity, recommend an action, and offer to eject after verification. Verify up-to-date installations in place and skip the stock download on working cards.
- Show copy and verification progress during stock-card preparation. Resume from saved progress or use `--resume` to finish an older interrupted stock copy while preserving existing files.
- Update the shell runtime in place with rollback, leaving mini apps and saves in their original directories.
- Provide diagnostics, explicit fresh-card preparation, and macOS format planning and confirmation.
- Add recorded shell-update recovery, source allowlisting, local reproducible archives, and CI artifact checks.
- Record the macOS connected-card check and FAT32 resume, recovery, and timing results separately from [pending physical acceptance](docs/VALIDATION.md#required-physical-acceptance-before-publication).

- Public branding is PocketLAB, including the project folder, UI name, SDK documentation, and archive prefix. Existing installation paths and identifiers remain compatible.
